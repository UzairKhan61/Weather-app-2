# SkyCast — Live Weather Dashboard

Responsive weather dashboard with animated cartoon weather scenes.

## Features
- Live weather using Open-Meteo (no API key required)
- City search with geocoding
- Browser location support
- Current temperature, feels-like temperature, humidity and wind
- 7-day forecast
- UV index and visibility
- Celsius/Fahrenheit toggle
- Responsive mobile navigation
- Animated cartoon weather scene
- Weather-specific rain/snow/storm animation
- No backend required

## Run
Open `index.html` in a browser. Internet access is required because the app fetches live Open-Meteo data.

For VS Code, Live Server is recommended.
